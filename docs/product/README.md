# Chariot — Product Documentation (Public)

**Tier:** Product Documentation — external, customer-facing.
**Audience:** customers, integrators, third-party adapter authors, security reviewers.
**Status:** This is the single dedicated **public** documentation space. Everything here is source-available and ships in the `@epicai/chariot` npm package.

Internal **Engineering Documentation** (design rationale, the full implementation-level specification, threat models, runbooks) is maintained privately in the `epic-ai` repository and is **not** published here.

## Contents
- `CHARIOT-SPEC.md` — integrator-facing specification (the interface contract; the comprehensive internal spec is private).
- `DEVELOPER_GUIDE.md` — integration guide.
- `SECURITY.md`, `SECURITY_ARCHITECTURE.md` — security policy + architecture.
- `DEPLOYMENT-REGULATED-ENVIRONMENTS.md` — regulated/air-gapped deployment.
- `BUNDLE_AUTHORITY.md`, `git-pin-contract.md` — catalog/supply-chain integrity.
- `Cross-App_Access_XAA_ID-JAG.md` — cross-app access (XAA / ID-JAG).
- `operator/`, `grafana/` — operator runbooks and dashboards.
